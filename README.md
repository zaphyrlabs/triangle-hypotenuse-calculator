# Triangle Hypotenuse Calculator (C++)

This is a simple C++ program that calculates the hypotenuse of a right-angled triangle using the Pythagorean Theorem.

I made this project while practicing basic C++ and math logic. It takes two sides of a triangle as input and returns the third side (hypotenuse).

## 📐 Formula Used
a² + b² = c²

## 🚀 How it Works
- User enters values of side a and side b
- Program calculates:
  c = sqrt(a² + b²)
- Displays the result

## 💻 Example
Input:
a = 9  
b = 12  

Output:
c = 15

## 🛠️ Technologies Used
- C++
- Standard Library (`<cmath>` for sqrt)
